# Linkedout
AI-powered workplace intelligence platform for anonymous employee experiences, review analysis, and company insights.
## Status

In Development

## Overview

LinkedOut is a full-stack web application designed to help employees
share workplace experiences anonymously and help job seekers understand
company culture through aggregated employee insights.

## Planned Features

- Anonymous employee reviews
- Company profiles
- Workplace ratings
- Sentiment analysis
- Workplace topic extraction
- Suspicious-review analysis
- Company-level analytics
- Review moderation

## Technology
